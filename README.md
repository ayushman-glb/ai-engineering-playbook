AI Engineering Playbook

A knowledge base for building software with AI effectively — not just prompting, but the full discipline around it: context engineering, agentic coding loops, token/cost optimization, runtime verification, and choosing the right model for the job.

Covers:

Prompting & context engineering — how to structure tasks so agents explore less and succeed faster
Agentic coding patterns — planning (GSD-style), verification loops (Ralph-style), runtime checks (Reticle), review (CodeRabbit)
Token optimization — context architecture, compaction, MCP tool design, model routing
Engineering discipline — anti-vibe-coding practices, scoped security testing, developer-knowledge-first workflows
Model landscape — comparing GPT, Claude, Gemini, Grok, DeepSeek, Qwen, and the products built on top of them (Cursor, Claude Code, Antigravity, Lovable)

This is a living document — updated as tools, models, and practices evolve
